# Monarch Themes 🎨

Monarch Themes is a custom Visual Studio Code theme extension designed for a clean, modern, and highly contrasted dark experience.

## Features

- Dark modern UI with purple accent highlights
- High contrast for better readability
- Classic VSCode syntax highlighting

## Installation

### From VSIX (local install)

1. Download the `.vsix` file from releases or build it yourself
2. Open Visual Studio Code
3. Go to **Extensions**
4. Click on **⋯ (three dots)** → *Install from VSIX...*
5. Select the `.vsix` file

Or via terminal:

```bash
code --install-extension monarch-themes-0.0.1.vsix
```
